# Rede Unishop — base em Next.js

Projeto inicial para reconstrução do site institucional da Rede Unishop.

## Tecnologias

- Next.js 16 com App Router
- React 19
- TypeScript
- Tailwind CSS 4
- Lucide React

## Rodar o projeto

```bash
npm install
npm run dev
```

Abra `http://localhost:3000`.

## Principais pastas

```text
src/app                 Rotas e páginas
src/components/home     Seções da página inicial
src/components/layout   Header e footer
src/components/ui       Componentes reutilizáveis
src/data                Dados temporários do site
public/images           Imagens reais da marca
```

## Próximas etapas sugeridas

1. Inserir logo e imagens oficiais em `public/images`.
2. Ajustar os textos com conteúdo aprovado pela empresa.
3. Conectar o formulário a e-mail, CRM ou banco de dados.
4. Criar integração com WordPress headless para conteúdos.
5. Adicionar mapa e cadastro real de lojas.

Os textos, números e depoimentos neste starter são demonstrativos e devem ser validados antes da publicação.
